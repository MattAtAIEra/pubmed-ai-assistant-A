# PubMed 知識殿堂

一座可以走進去的 3D 醫學圖書館，作為 PubMed AI 助理的操作介面。
使用者在櫃檯訂閱想追蹤的主題，系統定期到 PubMed 收新文獻、整理重點、擺上書櫃並通知使用者；
使用者可以在書櫃之間行走巡禮，或坐到窗邊書桌針對文獻多輪追問。

功能需求見 `doc/PubMed-AI-Assistant.pdf`。

## 目前進度

| 階段 | 內容 | 狀態 |
|---|---|---|
| 一、走得進去 | 玄關、大廳、書櫃、書桌、大窗；光影與書本質感；行走操作；陽光隨當地時間與天氣變化 | 完成 |
| 二、訂得到、收得到 | 登入、櫃檯訂閱、後端（Spring Boot）定期收書、真實文獻上架 | 尚未開始 |
| 三、讀得懂、問得到 | 單篇重點、每期歸納、通知、書桌多輪問答 | 尚未開始 |
| 四、進階與打磨 | PowerPoint 產出、第二種通知管道、畫質分檔、手機操作 | 尚未開始 |

第一階段書櫃上的書與名牌都是示意資料（見 `frontend/src/library.ts` 的 `CASES`）。

## 執行

```bash
cd frontend
npm install
npm run dev
```

打包：`npm run build`，產物在 `frontend/dist`。

## 操作方式

| 按鍵 | 動作 |
|---|---|
| ↑ / ↓（或 W / S） | 前進／後退 |
| ↑ 或 ↓ 加上 ← / → | 邊走邊轉向 |
| 只按 ← / →（或 A / D） | 橫向平移 |
| 滑鼠 | 轉動視線（點一下畫面鎖定滑鼠；不支援時按住拖曳） |
| Shift | 快走 |
| E 或 Enter | 互動：找館員、翻書、坐下 |
| M | 平面圖，點選可直接走過去 |
| Esc | 離開面板、站起來 |

右上角「時間與天氣」可以手動拖到任何時刻、切換天氣。
預設跟著瀏覽者當地的時間；位置由時區推估，天氣取自 Open-Meteo（只送出城市等級的座標）。

## 程式結構（frontend/src）

| 檔案 | 內容 |
|---|---|
| `main.ts` | 進入點：繪製設定、後製、互動、提示列、主迴圈 |
| `library.ts` | 建築：牆、窗、天花板、木拱架、書櫃、櫃檯、書桌、玄關，以及碰撞範圍 |
| `books.ts` | 書本：一萬多本書用同一個模型大量複製，每本各自的書背、厚薄與高矮 |
| `textures.ts` | 程式產生的材質：木紋、地板、石材、彩繪天花板、書背貼圖集、名牌 |
| `sky.ts` | 太陽位置計算、天空、天氣、光束與微塵、雨雪 |
| `controls.ts` | 行走與視線操作 |

網址參數（除錯與截圖用）：`?auto=1&hour=9&weather=clear&x=-15&z=0&yaw=-1.57`。
